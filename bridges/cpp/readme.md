mlx-cpp
---

The foundational Node.js bridge to Apple's MLX framework via C++.

> *Status: In Development.*

This package provides an alternative to [**mlx-swift**](https://www.npmjs.com/package/mlx-swift) by wrapping the core MLX C++ API directly. It aims to provide deep, low-level tensor/array manipulation and memory sharing capabilities for advanced machine learning research within Node.js.

*Internal package of [mlx-lm](https://www.npmjs.com/package/mlx-lm). Do not consume directly.*
