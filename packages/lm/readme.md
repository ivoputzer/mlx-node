# mlx-lm

Native Large Language Model execution for Node.js on Apple Silicon. Fast, memory-efficient text generation, chat sessions, and tool-calling using Apple's MLX framework.

No Python, no CMake, no complex setup. Just `npm install` and run local AI models on your Mac's GPU.


## Installation

```bash
npm install mlx-lm
```
*(Requires Node >= 20.12.0 and an Apple Silicon Mac running macOS 14+)*

## Basic Usage

```javascript
import { load, generate, stream, unload } from 'mlx-lm';

// 1. Load the model directly into GPU memory
const model = await load('/path/to/your/local/model');

// 2. Generate text (blocking)
const response = await generate(model, "Why is the sky blue?", {
  temperature: 0.7,
  topP: 0.9
})

console.log(response)

// 3. Generate text (streaming)
for await (const chunk of stream(model, "Write a poem about Node.js")) {
  process.stdout.write(chunk)
}

// 4. Free up GPU memory
unload(model)
```

## Using Chat Templates (with Hugging Face)

Most modern instruction-tuned models (like Llama 3 or Mistral) require specific formatting for chat conversations (e.g., `<|start_header_id|>user<|end_header_id|>`).

The easiest way to handle this in JavaScript is to pair `mlx-lm` with the official `@huggingface/transformers` library to apply the model's exact chat template before passing it to the MLX GPU engine.

```bash
npm install @huggingface/transformers
```

```javascript
import { load, stream, unload } from 'mlx-lm';
import { AutoTokenizer } from '@huggingface/transformers';


const modelPath = '/path/to/local/Llama-3-8B-Instruct'

// 1. Load the tokenizer and the MLX model
const tokenizer = await AutoTokenizer.from_pretrained(modelPath)
const model = await load(modelPath)

// 2. Define your conversation
const messages = [
  { role: 'system', content: 'You are a helpful AI assistant.' },
  { role: 'user', content: 'Explain quantum computing in one sentence.' }
]

// 3. Apply the Chat Template (returns a formatted string, not tokens)
const prompt = tokenizer.apply_chat_template(messages, {
  tokenize: false,
  add_generation_prompt: true
})

// 4. Stream the generation via MLX
process.stdout.write('AI: ')
for await (const chunk of stream(model, prompt)) {
  process.stdout.write(chunk)
}

unload(model)
```

## API Reference

### `load(path: string): Promise<number>`
Loads a model into GPU memory and returns a unique `modelId`.
- `path`: Absolute path to the local model directory (must contain tokenizer and weights).

### `unload(modelId: number): boolean`
Removes the model from memory and destroys the context. Returns `true` if successful.

### `generate(modelId: number, prompt: string, config?: GenerateConfig): Promise<string>`
Generates a complete response string asynchronously.
- `config.temperature` (default `0.6`)
- `config.topP` (default `1.0`)
- `config.repetitionPenalty` (default `1.0`)

### `stream(modelId: number, prompt: string, config?: GenerateConfig): AsyncGenerator<string>`
Returns an async iterable stream of text chunks as they are generated by the GPU.
- `config.streamChunkSize` (default `4`): How many tokens to evaluate before flushing back to JavaScript. Lower is smoother, higher is slightly faster.
