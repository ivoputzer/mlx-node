# mlx-llm

Native Large Language Model (LLM) execution for Node.js on Apple Silicon.

> [!WARNING]
> **Merged Package:** This package is currently an alias of `mlx-lm`.

To streamline the ecosystem, both text-based LLMs (Large Language Models) and VLMs (Vision-Language Models) are handled by a single unified package: `mlx-lm`.

Installing `mlx-llm` will automatically install and resolve `mlx-lm`.

### Documentation
Please refer to the [**`mlx-lm` repository**](https://github.com/ivoputzer/mlx-node/tree/main/packages/lm) for documentation, usage examples, and API references.
